# MediGraph: Dual-Layered Explainable AI and Literature-Grounded RAG for Drug-Target Interaction and Repurposing

## Abstract
Computational drug repurposing accelerates therapeutic discovery by identifying novel indications for established chemical compounds. However, machine learning models predicting drug-target (DTI) and drug-drug interactions (DDI) often operate as opaque predictive engines, generating classification probabilities without biological context. To address this interpretability barrier, we introduce **MediGraph**, a dual-layered explainable machine learning framework for interaction prediction and repurposing candidate discovery. MediGraph constructs a 262-dimensional molecular feature space combining 128-bit ECFP4 Morgan fingerprints and physicochemical descriptor differences derived from ChEMBL and DrugBank databases to train ensemble classifiers. To bridge statistical inference with biomedical validity, the framework incorporates a two-stage explainability engine: local structural feature contributions are quantified using game-theoretic SHAP (SHapley Additive exPlanations) values, while biological mechanisms are contextualized using a Retrieval-Augmented Generation (RAG) architecture that grounds Large Language Model (LLM) reasoning in peer-reviewed PubMed literature. Empirical evaluation demonstrates robust classification performance alongside verifiable biological rationales, providing a rigorous methodological framework for interpretable computational drug discovery.

## 1. Introduction

Modern pharmaceutical research increasingly relies on computational drug repurposing to bypass the extensive timelines and capital investment associated with *de novo* compound synthesis. By mining large-scale bioactivity databases such as ChEMBL and DrugBank, supervised machine learning (ML) frameworks can predict uncharacterized Drug-Target Interactions (DTIs) and Drug-Drug Interactions (DDIs). Despite achieving high classification accuracy, standard predictive architectures produce isolated numerical probabilities that fail to convey the underlying biochemical mechanisms governing interaction dynamics. Consequently, biomedical researchers encounter an interpretability barrier, where statistical likelihood alone provides insufficient justification for costly wet-lab validation.

Overcoming this limitation requires moving beyond predictive accuracy toward transparent, mechanistic decision-making. Feature attribution methods based on cooperative game theory, such as SHAP (SHapley Additive exPlanations), effectively quantify the contribution of individual chemical features—such as specific molecular substructures or physicochemical properties—to model output. However, post-hoc feature importance scores isolate *what* chemical features drive the prediction without explaining *why* those features trigger a specific physiological response. Conversely, while Large Language Models (LLMs) demonstrate advanced biomedical text generation capabilities, their direct application in scientific research is constrained by hallucination risks. Integrating Retrieval-Augmented Generation (RAG) mitigates this limitation by constraining generative text synthesis to facts retrieved from peer-reviewed literature databases like PubMed.

To unify quantitative structural attribution with literature-backed biomedical reasoning, we propose **MediGraph**, an interpretable machine learning framework for interaction prediction and drug repurposing. The pipeline converts molecular SMILES representations into high-dimensional feature vectors incorporating Morgan fingerprints (radius=2, ECFP4) and physicochemical deltas ($\Delta\text{MW}$, $\Delta\text{LogP}$, $\Delta\text{HBD}$, $\Delta\text{HBA}$, $\Delta\text{PSA}$) for ensemble classification. Upon predicting an interaction, MediGraph executes a dual-layer interpretability workflow: SHAP decomposes model outputs into exact feature-level structural attributions, while a PubMed-connected RAG engine retrieves relevant academic abstracts to generate verifiable mechanistic rationales.

The primary contributions of this work are as follows:
- **Dual-Layered Explainability Architecture**: A hybrid interpretability framework that couples game-theoretic SHAP structural feature attributions with literature-anchored RAG synthesis to explain machine learning predictions.
- **Hallucination-Constrained RAG Engine**: A retrieval-augmented generation pipeline that dynamically extracts PubMed abstracts to ground LLM-generated biological rationales strictly in peer-reviewed scientific evidence.
- **End-to-End Methodological Pipeline**: An integrated computational workflow encompassing data ingestion (ChEMBL/DrugBank), molecular feature engineering, ensemble interaction scoring, and automated rationale generation for drug repurposing.
